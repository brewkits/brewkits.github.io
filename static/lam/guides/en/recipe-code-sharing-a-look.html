What is a LAM recipe code?

~4 min read

Instead of screenshotting five sliders and texting a friend "match this," LAM packs an entire look — film stock, grain, strength, skin-tone mode and a few other choices — into a single 8-character string, like LAM-9F3KQ2XY. Paste that string into LAM and you get the exact look instantly, no guessing, no manual re-tuning.

You shoot a photousing a specific look
→
LAM packs itinto an 8-char code
→
You share itunder a TikTok / in a DM
→
A friend pastes itsame look in 5 seconds

What the code holds, and what it doesn't

The code only encodes the look's parameters — film stock, grain, filter strength, skin-tone mode, and a couple of other choices — it never contains a photo or any personal data. Pasting it on another phone only applies that exact colour recipe to a NEW photo that person shoots — it can't reach your original image at all. No account or sign-in is needed to use one either.

The code carries a checksum. If someone mistypes a character copying it by hand instead of pasting, LAM flags it as invalid immediately — it never silently applies the wrong look without anyone noticing.

Why this isn't just a minor feature

In most photo editors, "I love this colour, how do I get it" has no real answer — a filter is a closed black box, not something you can decompose into shareable parameters. An 8-character code turns that question into a 5-second action: copy, paste, done — no need to know what the film stock is called or how many percent any slider was pushed.
